# Семейный переполох

Существующая браузерная игра модернизирована до семейной колоды из **13 типов и 56 физических экземпляров**. Сохранены React + TypeScript (strict), Vite, Tailwind CSS, Motion, Zustand, прежние меню и стол, боты, локальная передача устройства, звук и автосохранение. Новый сервер не требуется.

## Запуск

Нужен Node.js 22.12+ или 24 LTS с npm:

```sh
npm install
npm run dev
```

Откройте адрес Vite в браузере. Для точного повторения установки в CI используйте `npm ci`. Игра работает на компьютере, планшете и смартфоне; на телефоне удобнее открыть опубликованную страницу, чем устанавливать инструменты разработки.

```sh
npm run test       # Vitest: правила, боты, сохранение и инварианты
npm run build      # строгий TypeScript + production-сборка dist/
npm run preview    # локальный просмотр собранной версии
```

Для браузерных проверок:

```sh
npx playwright install chromium
npm run test:browser
npm run build
npm run test:pages
```

Если Chromium установлен системой, задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`. Playwright запускает Vite автоматически. `test:pages` раздаёт настоящий `dist/` из временного локального HTTP-сервера под `/my-card-game/` и `/Eugenix/`, без подмены ответов браузера.

## GitHub Pages / Android

1. Перенесите изменения в `main` через Pull Request → Merge.
2. **Settings → Pages → Source → GitHub Actions** (не Deploy from a branch).
3. Дождитесь зелёного задания **Build, test and publish game** в Actions; при необходимости нажмите Run workflow для `main`.
4. Откройте адрес Pages. Текущий репозиторий: `https://treugenix-cmyk.github.io/Eugenix/`; после переименования в `my-card-game` адрес будет `/my-card-game/`.

Workflow `.github/workflows/pages.yml` проверяет PR, а после обновления `main` собирает и публикует только `dist/`. Vite использует `base: './'`, поэтому все изображения, стили и скрипты корректно загружаются из подпапки проекта. Через `file://` эта версия не запускается: используйте Vite или статический хостинг. Регистрация и сервер игровой логики не нужны.

## Подготовка партии

Для 2–5 игроков:

1. Создаются все 56 экземпляров. Четыре Папы и шесть Мам временно отделяются.
2. Каждый получает одну Маму.
3. Остальные 46 карт перемешиваются, каждому выдаётся ещё семь. В руке **8 стартовых карт**.
4. В колоду добавляется до двух оставшихся Мам и `число игроков − 1` Пап.
5. Колода перемешивается. Неиспользованные Мамы и Папы сохраняются в отдельном массиве `excluded`, вне игровой колоды. Первым, как раньше, ходит первый игрок.

| Игроков | В руке у каждого | Пап в колоде | Дополнительных Мам | Исключено | Всего в партии |
| ------: | ---------------: | -----------: | -----------------: | --------: | -------------: |
|       2 |                8 |            1 |                  2 |         5 |             51 |
|       3 |                8 |            2 |                  2 |         3 |             53 |
|       4 |                8 |            3 |                  2 |         1 |             55 |
|       5 |                8 |            4 |                  1 |         0 |             56 |

Не путайте полную конфигурацию из 56 экземпляров с числом участвующих в конкретной партии карт. Состав всех зон, включая исключённые карты и временно вытянутого Папу, всегда равен 56.

## Ходы и действия

- Ходим **только по часовой стрелке**. Разворота направления больше нет.
- В свой ход можно сыграть несколько действий и комбинаций последовательно или ничего не играть. Взятие верхней карты происходит в конце хода и завершает одно обязательство.
- Лимита руки и обязательного добора до восьми нет.
- **Папа:** не попадает в руку. Без Мамы игрок выбывает; его рука и Папа идут в сброс. Последний живой побеждает. Долг выбывшего исчезает, следующий живой получает обычный ход.
- **Мама:** расходуется для спасения. Папа тайно возвращается на любую позицию: верх, низ или промежуток. Порядок остальных карт сохраняется. Завершается одно обязательство, оставшиеся после атаки сохраняются.
- **Пропуск:** завершает одно обязательство без взятия.
- **Атака ×2:** в обычном ходе передаёт следующему два хода; при ответной атаке передаёт весь оставшийся атакованный долг плюс два. Примеры: `2 → 4`; если один из двух ходов уже выполнен, ответная атака передаёт `3`.
- **Будущее:** тайный просмотр до трёх верхних карт без изменения порядка. Можно отменить до просмотра, но не после раскрытия.
- **LEGO:** Fisher–Yates перемешивает только оставшуюся колоду. Руки, сброс и исключённые карты не меняются. Старые сведения о верхних картах забываются.
- **FAVOR:** выберите живого соперника. Он сам выбирает одну карту из своей руки и отдаёт её. Получатель не называет тип и не выбирает случайную карту. При пустой руке ничего не передаётся.
- **Пять семейных типов:** поодиночке не имеют действия; нужны для комбинаций.

## Пары и тройки

Нажмите **«Комбинация · 2 или 3 карты»**, выберите экземпляры и подтвердите действие:

- **Две одинаковые:** выберите соперника и случайно получите одну его карту.
- **Три одинаковые:** выберите соперника и назовите тип. Если такой тип есть, получите один экземпляр; иначе ничего.

Можно комбинировать любые одинаковые карты, законно находящиеся в руке, включая действия, Мам и NOPE. Их обычные эффекты не исполняются. Повторное использование одного физического ID не допускается. Комбинаций четырёх, пяти или пяти разных карт нет. На пустой руке соперника комбинация завершается без передачи. Выбывшего или себя выбирать нельзя.

## NOPE — отмена и отмена отмены

«Зоя выгоняет из комнаты» теперь **NOPE**, а не разворот. Действие или комбинация сначала попадает в отдельное окно отмены. При необходимости цель и запрашиваемый тип выбираются до этого окна, чтобы отвечающие понимали, что отменяют.

Живые соперники отвечают по очереди, по часовой стрелке: **«Сыграть NOPE»** или **«Не отменять — дальше»**. Ответы предлагаются всем, независимо от наличия NOPE: это не раскрывает, у кого она есть. Боты решают сами по собственному представлению состояния.

Каждая NOPE отправляется в сброс, переключает чётность отмены и начинает новый круг ответов всех остальных живых игроков. Нельзя отменить собственную последнюю карту; автор исходного действия может ответить на чужую NOPE.

- Действие + 1 NOPE → отменено.
- Действие + 2 NOPE → активно.
- Действие + 3 NOPE → отменено.

Когда все остальные ответили, действие либо исполняется ровно один раз, либо окончательно отменяется. Поздняя отмена не принимается. Исходные карты и NOPE остаются в сбросе; при отмене обычный ход автора продолжается, долг не списывается.

**Нельзя отменить:** само взятие карты, взрыв Папы, спасение Мамой, возврат Папы, выбор отдаваемой карты после уже разрешённого FAVOR и уже выполненный просмотр/эффект. NOPE вне окна отмены недопустима как одиночное действие, но несколько NOPE можно использовать в комбинации.

Защитное правило существующего проекта для пустой колоды сохранено: попытка взять из пустой колоды завершает партию совместной победой оставшихся. Сброс обратно не перемешивается.

## Режимы, интерфейс и сохранение

- **Боты:** один человек и 1–4 соперника, три уровня сложности. Ботам передаётся только `PlayerView`: своя рука, публичные количества/сброс/журнал и собственные сведения о будущем. Чужие руки и порядок колоды недоступны. Обновлены решения по отменам, комбинациям и выбору отдаваемой карты.
- **Локально:** 2–5 человек. Экран передачи устройства скрывает руку перед каждым обязательством, ответом NOPE и передачей карты. Пока не нажато «Я готов», чужая рука и тайные модальные выборы не отрисовываются. После перезагрузки защита включается снова.
- **Изображения:** все 13 PNG взяты из предоставленного `family_13_cards.zip` и помещены в `public/cards/family/` без изменения байтов. Включена окончательная версия Таниного танца с разбросанными вещами. `object-fit: contain` сохраняет пропорции, лица и названия. Кнопка «Увеличить» открывает полный портрет и актуальное описание эффекта. Старые SVG и исторические загруженные материалы не удалены, но активные карты используют предоставленные PNG.
- **Автосохранение:** новая партия сохраняется после каждой принятой команды, включая выбор цели, цепочку NOPE, отдачу карты, просмотр и возврат Папы. Команды проверяют автора решения, фазу и ожидаемую ревизию; повторные команды не теряют и не дублируют карты.
- **Совместимость:** новый формат — `family-chaos.game.v2`. Партии на 39 картах несовместимы с новой колодой, поэтому не мигрируются в середине игры; старое сохранение `family-chaos.game.v1` не стирается. Браузер показывает понятное сообщение. Настройки анимаций и звука остаются совместимыми.
- Звук, выключение анимаций и системное уменьшение движения сохранены. «В меню» приостанавливает ботов. Новый сервер и фреймворк не добавлены.

## Архитектура сохранена и расширена

- `src/cards/` — 13 канонических типов, эффекты, количества, локальные пути.
- `src/deck/` — конфигурация, безопасная раздача, исключённые экземпляры, Fisher–Yates.
- `src/game-engine/` — расширенный существующий движок: `phase`, `pending`, очередь ответов NOPE, комбинации, FAVOR и приватные представления.
- `src/turn-manager/` — порядок по часовой стрелке и отдельный счётчик долга.
- `src/bots/` — решения без доступа к скрытой информации.
- `src/components/` — прежние экраны, расширенные выборы, комбинации и увеличение изображений.
- `src/storage/` — существующий Zustand, новая проверка формата и сохранности всех 56 ID, localStorage.
- `src/transport/` — сохранён контракт будущего транспорта; сетевого режима в исходном проекте не было и WebSocket-сервер не добавлялся.
- `src/animations/`, `src/style.css` — прежние эффекты и оформление с дополнениями для новых контролов.
- `src/tests/`, `tests/browser/`, `scripts/check-pages.mjs` — обновлённые проверки.

Подготовка раздачи и переход между обязательствами атомарны внутри движка. Доступные интерактивные фазы: обычный ход, выбор цели, окно NOPE, выбор отдаваемой карты, взрыв, возврат Папы, просмотр и завершение. Защита при передаче устройства управляется существующим интерфейсом по текущему принимающему решение игроку; полный `GameState` никогда не передаётся боту.

## Правила, источники и ограничения

Приоритет имеют конкретные соответствия и примеры пользовательского задания. Источники для сверки базовых правил: https://www.explodingkittens.com/pages/rules-kittens и https://www.explodingkittens.com/pages/comprehensive-field-guide. Во время этой разработки оба адреса были недоступны из окружения (`403`); прямая сверка актуального текста не заявляется. Механики расширений, разворот и комбинация из пяти разных карт не добавлены.

Сохранения принадлежат текущему браузеру и адресу сайта, не синхронизируются между устройствами. Локальное скрытие защищает от случайного взгляда, но не от просмотра localStorage через инструменты разработчика. Не открывайте одну партию параллельно в нескольких вкладках. Физические Android/iOS не проверялись — браузерные тесты используют Chromium с мобильной эмуляцией. Онлайн остаётся будущим этапом.
