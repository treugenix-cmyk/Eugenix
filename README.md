# Семейный переполох

Полноценная семейная карточная игра: один человек против 1–4 ботов или 2–5 друзей на одном устройстве. Без регистрации, учётных записей и игрового сервера. React + TypeScript (strict), Vite, Tailwind CSS, Motion, Zustand. Настройки и партия хранятся в localStorage браузера.

## Запуск на компьютере

Нужен Node.js 22.12+ (или 24 LTS) с npm.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite. Чтобы играть с телефона в одной Wi-Fi сети с компьютером, откройте его сетевой адрес и разрешите доступ через локальный брандмауэр. Для обычной игры с Android удобнее опубликованная страница ниже; установка Node на телефон не нужна.

```sh
npm run test          # все автоматические тесты Vitest
npm run build         # строгая проверка TypeScript и сборка в dist/
npm run preview       # локальный просмотр собранной версии
```

В CI и для точного повторения установки используйте `npm ci`: версии зафиксированы в `package-lock.json`.

Дополнительные браузерные проверки:

```sh
npx playwright install chromium
npm run test:browser
npm run build
npm run test:pages    # собранная игра под /my-card-game/ и /Eugenix/
```

Если Chromium уже установлен системой, можно передать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`. Playwright сам запускает Vite для тестов. Эта зависимость нужна только разработчику, игрок ничего не устанавливает.

## Как открыть на Android / GitHub Pages

В репозитории есть `.github/workflows/pages.yml`: при pull request запускаются проверки и сборка, при обновлении `main` публикуется только `dist/`.

1. Перенесите изменения в `main` через Pull Request → Merge.
2. На GitHub откройте **Settings → Pages → Source → GitHub Actions**. Это важно: прежний способ «Deploy from a branch» не собирает React/TypeScript.
3. Дождитесь зелёного задания **Build, test and publish game** в **Actions**. При необходимости запустите его через **Run workflow**.
4. Откройте адрес из Pages на телефоне. Для текущего репозитория — `https://treugenix-cmyk.github.io/Eugenix/`. При переименовании репозитория в `my-card-game` адрес будет оканчиваться на `/my-card-game/`.

Vite настроен с `base: './'`: собранные скрипты, CSS и SVG используют относительные пути и работают под префиксом проекта. Загрузка `index.html` прямо через файловый менеджер (`file://`) для этой версии не поддерживается: используйте Vite или Pages. Одиночная игра не требует серверной игровой логики; Pages просто раздаёт статические файлы.

## Как играть

Оставайтесь последним живым игроком. Во время хода можно сыграть несколько доступных карт, затем нажать на колоду. Обычная вытянутая карта идёт в руку и завершает одно обязательство. Карты в руках соперников не раскрываются. Сброс и журнал событий открыты всем.

### Конфигурация — 39 карт, ровно 10 типов

| Карта                         | Количество | Действие                                                             |
| ----------------------------- | ---------: | -------------------------------------------------------------------- |
| Папа с ремнём                 |          4 | При вытягивании опасность: без защиты игрок выбывает                 |
| Мама с салатом                |          6 | Обязательная защита от опасности; затем тайная вставка Папы в колоду |
| Таня с градусником            |          4 | Завершить одно обязательство без взятия                              |
| Зоя выгоняет из комнаты       |          4 | Развернуть очередь; вдвоём пропустить соперника                      |
| Маша и Аркаша подрались       |          4 | Передать два хода; ответная атака передаёт оставшийся долг + 2       |
| Зоя смотрит в бинокль         |          5 | Тайно посмотреть до трёх верхних карт, сохраняя порядок              |
| Аркаша разбросал LEGO         |          4 | Перемешать только колоду, забыть устаревшие сведения                 |
| Маша делает уроки с мамой     |          4 | Запросить один определённый безопасный тип у живого соперника        |
| Зоя просит денег у папы       |          2 | Положить другую карту из руки наверх колоды, продолжить ход          |
| Таня кладёт денежки в копилку |          2 | Положить другую карту под низ колоды, продолжить ход                 |

Каждый получает **одну Маму и четыре случайные карты действий**. Оставшиеся Мамы добавляются в колоду после раздачи. Затем добавляется `число игроков − 1` опасностей и всё перемешивается. Из четырёх опасностей неиспользованные остаются вне партии: с 2/3/4/5 игроками в игре участвует 36/37/38/39 карт соответственно. Все шесть Мам и 29 карт действий участвуют всегда. Повторов экземпляров по ID нет.

### Уточнения правил

- При опасности нажмите «Мама, спаси!», затем выберите верх, низ или конкретную позицию. Позиция 1 — верх. Журнал не раскрывает выбранную позицию.
- Защита расходуется; опасность возвращается. Без защиты рука и опасность уходят в сброс, игрок выбывает. Его накопленные обязательства исчезают; следующий живой игрок начинает обычный ход.
- Атака в обычном ходе передаёт **2** обязательства. При долге **4** ответная атака передаст **6**; если сначала пропустить одно обязательство, она передаст **5**. Даже если остался только один атакованный ход, ответная атака передаст **3**.
- Разворот при 3+ игроках меняет направление, не завершает текущий ход и не списывает долг. Вдвоём завершает одно обязательство текущего игрока, пропускает соперника; текущий игрок продолжает со следующим обязательством или новым обычным ходом.
- Просмотр доступен только сыгравшему карту. Боты используют только свою руку, публичные данные и собственный просмотр; скрытый порядок колоды им не передаётся.
- Запрошенный тип и факт передачи видны в журнале, другие карты соперника — нет. При отсутствии нужной карты ничего не передаётся. Папу запрашивать нельзя.
- Для верха/низа выбирается другая карта после расходования активирующей. Если другой карты нет, действие недоступно.
- **Пустая колода:** при попытке взять карту партия завершается совместной победой всех оставшихся игроков. Сброс не возвращается. Это исключает бесконечное ожидание.
- Побеждает последний живой. После завершения можно начать новую партию.

## Режимы, сохранение и настройки

- **Боты:** лёгкие в основном выбирают случайные действия; средние используют просмотр и сберегают защиту; сложные дополнительно оценивают публичную вероятность опасности, число игроков и долг. Все решения вновь проверяет движок.
- **Локально:** перед каждым обязательным ходом показывается экран передачи устройства. Пока игрок не нажал «Я готов», рука не отрисовывается. После перезагрузки экран защиты возвращается даже посреди тайного действия.
- **Продолжить партию:** после каждого принятого действия сохраняется состояние, включая выбранную опасность, запрос или просмотр. Нажмите «В меню», чтобы приостановить ботов, и «Продолжить партию», чтобы вернуться. Сохранение принадлежит текущему браузеру и адресу сайта, не переносится между устройствами. Повреждённое сохранение не загружается и не перезаписывается автоматически.
- Анимации и звук включаются/выключаются в настройках. Системное `prefers-reduced-motion` отключает движение независимо от переключателя. Звук синтезируется Web Audio, по умолчанию выключен и активируется нажатием пользователя. Внешних аудиофайлов нет.
- Все десять иллюстраций — собственные локальные SVG, выполненные в едином стиле. Внешних ссылок и материалов Exploding Kittens нет.

## Структура исходного проекта

- `src/cards/` — типы, количества, названия и подсказки карт.
- `src/deck/` — полная конфигурация, перемешивание, безопасная раздача.
- `src/game-engine/` — чистый движок, команды, фазы выбора, допустимость действий, публичные представления.
- `src/turn-manager/` — очередь, направление, накопление атак.
- `src/bots/` — три сложности; вход — только `PlayerView`.
- `src/components/` — React-экраны, карты, модальные выборы, правила.
- `src/animations/` — локальные звуковые эффекты; анимации Motion находятся рядом с компонентами.
- `src/storage/` — Zustand, проверка формата/состава сохранения, localStorage.
- `src/transport/` — контракт для будущего транспорта и локальная реализация.
- `src/tests/` — Vitest; `tests/browser/` — Playwright.
- `public/cards/` — десять оригинальных SVG; `src/style.css` — адаптивное оформление с Tailwind.

Каждая команда содержит автора и ожидаемую ревизию. Повторная команда, чужой ход и действие не в своей фазе отклоняются без изменения состояния. Выборы верха/низа и вставки опасности завершаются атомарно.

## Онлайн — второй этап и ограничения

WebSocket-сервер не реализован и не требуется для двух доступных режимов. `GameTransport` определяет контракт отправки команд и получения только представления конкретного игрока. Для сети потребуется авторитетный сервер, аутентификация участников и проверка автора команды на сервере; нельзя передавать полный `GameState` клиентам.

Локальная приватность защищает от случайного взгляда при передаче телефона, но не от человека, исследующего localStorage или JavaScript через инструменты разработчика. Не открывайте одну партию одновременно в нескольких вкладках: синхронизация вкладок не предусмотрена. Очистка данных браузера удалит сохранение. Физический Android и iOS требуют отдельной проверки на реальных устройствах; автоматические проверки используют мобильный Chromium.

Старые загруженные портреты и папка `family-chaos/` с ранее опубликованными сборками сохранены как исторические материалы. Новая версия запускается из корневого `index.html`, собирается из `src/` и не использует эти старые сборки. Старые `game.js` и `style.css` заменены исходными модулями в `src/`. Новая сборка в `dist/` не добавляется в Git; Pages собирает её через Actions.

## Выполненные проверки

- 37 тестов Vitest: все эффекты карт, очередь и атаки, скрытые сведения, защита от повторных команд, сохранение. В том числе 90 полных партий ботов с проверкой сохранности каждого типа карт после каждого действия.
- 6 сценариев Playwright: полная партия с четырьмя ботами, локальная передача, восстановление незавершённых действий, правила, иллюстрации, уменьшение движения и размеры 320/390/768/1440 px.
- `npm run build`: строгий TypeScript и production-сборка.
- `npm run test:pages`: настоящий `dist/` раздаётся из временного локального HTTP-сервера под `/my-card-game/` и `/Eugenix/`; проверяются запуск, десять SVG и восстановление партии. Подмена сетевых ответов браузера не используется.

Эти результаты относятся к текущей реализации и локальному Chromium с мобильной эмуляцией. Публикация на GitHub Pages и проверка физического телефона выполняются отдельно.
