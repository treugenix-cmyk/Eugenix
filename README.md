# Четыре героя

Карточная игра против компьютера на HTML, CSS и JavaScript. Без библиотек, npm, сервера, базы данных и внешних запросов.

## Как открыть с Android

Самый удобный вариант — GitHub Pages:

1. Сохраните все четыре файла в корне ветки `main` своего репозитория (см. ниже).
2. Откройте репозиторий на GitHub → **Settings → Pages**. Если меню скрыто, включите в меню браузера «Версия для ПК».
3. Выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Через несколько минут откройте ссылку, показанную в Pages. Для этого репозитория: https://treugenix-cmyk.github.io/Eugenix/
5. При желании добавьте страницу на главный экран через меню Chrome.

Pages бесплатно работает для публичных репозиториев; доступность для приватных зависит от тарифа GitHub. После публикации игра доступна другим людям по ссылке. Для загрузки страницы нужен интернет.

### Локально без интернета

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и откройте `index.html` в браузере через файловый менеджер. `index.html`, `style.css`, `game.js` должны находиться в одной папке. Некоторые Android-файловые менеджеры открывают HTML в ограниченном предпросмотре, где соседние файлы и JavaScript недоступны. В таком случае используйте Pages. Открытие файла в списке файлов GitHub показывает код, а не запускает игру.

## Как сохранить изменения в GitHub с телефона

Если интерфейс Codex предлагает создать pull request: создайте его, откройте на GitHub и нажмите **Merge pull request → Confirm merge**, чтобы изменения попали в `main`.

Универсальный способ без команд:

1. Скачайте подготовленные `index.html`, `style.css`, `game.js`, `README.md` из рабочего пространства на телефон.
2. Откройте свой репозиторий GitHub, выберите `main`, затем **Add file → Upload files**. При необходимости включите «Версия для ПК» в браузере.
3. Загрузите четыре файла в корень репозитория, напишите «Добавить игру Четыре героя» и нажмите **Commit changes**. Для существующего README подтвердите обновление. Если замена через загрузку недоступна, откройте README, нажмите карандаш, замените текст и сохраните через **Commit changes**.
4. Проверьте, что все файлы находятся рядом, в корне. Если Pages включён, он обновится автоматически после сохранения в `main`.

## Правила

У каждого по 5 случайных карт с силой от 1 до 5. Буся, Каник, Танюня и Воя-Боя встречаются с одинаковой вероятностью: 25% на каждую карту. Повторы допустимы. Компьютер использует те же правила.

- Буся побеждает Каника, Каник — Танюню, Танюня — Вою-Бою, Воя-Боя — Бусю, независимо от силы.
- Противоположные пары без преимущества: Буся и Танюня; Каник и Воя-Боя.
- Для одинаковых персонажей и пар без преимущества побеждает большая сила. При равной силе — ничья.
- Подсказку «Кто кого побеждает» можно раскрыть в любой момент игры.
- Нажмите свою карту. Компьютер случайно выбирает одну из оставшихся карт. Сыгранные карты удаляются из рук.
- За победу в раунде — 1 очко, за ничью — 0. После пяти раундов сравнивается счёт.
- «Новая игра» сбрасывает раздачу и счёт в любой момент.

## Файлы

- `index.html` — экран игры.
- `style.css` — тёмное фэнтези, мобильная вёрстка, анимации; учитывается системное уменьшение движения.
- `game.js` — правила, случайная раздача, счёт и управление раундами.

Для разработки достаточно текстового редактора и браузера. Сборка и установка зависимостей не нужны.
